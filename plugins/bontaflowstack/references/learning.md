# Learning workspace contract

## Practice

Use a new empty directory owned by the practice task. Check it before writing;
an existing file or nonempty folder belongs to its owner and is never replaced.
Keep the exercise runnable with the project's available runtime, use synthetic
inputs and include one observable check. Create only the task, needed starter,
check and a short run guide. Do not copy the source project or credentials.

## Review and retention

Evaluate stated objectives against changed files and actual check output. A green
exercise proves only that check, not general mastery or completion of a product
requirement. Report missing evidence explicitly. Recommend a next exercise from
the observed gap.

Persist a general lesson only on explicit request. Use the selected project's
existing memory learning lifecycle with observed or inferred provenance, an
actual source reference, relevant files and expected revision for updates. Read
back the record. Never change global instructions or silently write to another
project.
