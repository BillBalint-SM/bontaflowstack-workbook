# BFS Plan CEO Review

Read [HOST.md](../../HOST.md) for execution, state and authorization rules.
Modes: `bfs-review`. Choose the mode from the actual request.

1. Identify the decision, intended customer, proposed value and evidence for the underlying problem.
2. Examine adoption assumptions, differentiators, alternatives, costs, operational demands and the smallest useful outcome.
3. Compare keeping, reducing or changing the proposed scope. Treat scope expansion as a product decision for the user.
4. Look for failure conditions: insufficient demand, unclear ownership, missing distribution, unmeasurable success or dependencies outside the team's control.
5. Give concrete findings tied to the plan, the proposed adjustment and an acceptance signal. Separate missing evidence from a disproven idea.
6. Return a prioritized recommendation and unresolved decisions. Amend the plan only within the requested editing scope.
